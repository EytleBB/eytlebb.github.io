# Forest redesign fonts

Self-hosted Latin WOFF2 subsets retrieved from the official Google Fonts CSS API on 2026-09-12. Existing Minecraft fonts are unrelated and untouched. Chinese and Korean text continue to use system fonts.

- Cormorant Garamond, 400 normal: `cormorant-garamond-latin-400.woff2`
- Cormorant Garamond, 400 italic: `cormorant-garamond-latin-400-italic.woff2`
- Manrope, variable weight 200–800, normal: `manrope-latin-variable.woff2`

Use `font-display: swap`. Both families are distributed under the SIL Open Font License; the accompanying OFL files are copied from the official google/fonts repository.
