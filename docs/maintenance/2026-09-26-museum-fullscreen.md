# 手机展馆画质与全屏修订 · 2026-09-26

按用户要求，手机端使用与电脑端相同的渲染配置；首次点击“进入展馆”时请求全屏，并提供可手动进入、退出、重试的全屏按钮。

基线为最新 `main` 的 `adff4e9`。功能分支：`codex/museum-mobile-fullscreen`；工作树：`/home/yeom/.codex/worktrees/museum-mobile/thisIsEytle`。只提交功能，不推送或部署，由发布会话审查集成。

## 画质

- 移除手机专用 DPR 1.25、1024px 纹理缩小、各向异性 4 和反射 768px 限制。
- 手机和电脑均使用 `min(devicePixelRatio, 2)`；主场景和反射均使用 `min(4, maxSamples)`；完整的同一批画廊预览纹理、设备支持的最大各向异性，以及 1536px 的反射尺寸预算。
- `museum-architecture.js` 恢复为手机模式加入前的桌面实现，纹理解码也恢复为共享路径。没有按设备降低灯光、材质、阴影、雾、后处理或帧率设置。
- 保留手机触控、竖屏取景、横竖屏布局及输入释放逻辑。

## 全屏

- 原生请求发生在首次点击进入按钮的同步阶段，不依赖加载完成后的异步用户激活。全屏被拒绝时照常进入展馆。
- 入口 / 暂停菜单和手机 HUD 均有“全屏 / 退出全屏”按钮；状态根据浏览器 `fullscreenchange` 更新。手动退出后暂停再继续，不会强制重新全屏。
- `js/museum-fullscreen.js` 处理标准和 WebKit 前缀接口、请求中的重复点击、拒绝与异步错误。浏览器不支持网页全屏时说明原因，仍可正常参观。
- 相关 JS、CSS 引用已更新缓存版本。全屏 UI 使用现有中英韩文案和安全区布局。
