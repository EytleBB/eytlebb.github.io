# 网站协作与发布流程

自 2026-09-18 起，网站修改与发布分开进行。

## 功能任务

每项功能使用独立 Git worktree 或分支，从最新 `main` 开始。功能任务只负责实现、测试并提交本功能，不直接推送 GitHub 或腾讯云。这样多个会话不会共享未提交改动，也不会互相覆盖、混入提交或损坏索引。

## 发布会话

标题为“Eytle 网站发布会话”的 Codex 会话在仓库根目录工作，是唯一可以发布的会话。它负责：

1. 审核并整合已经完成的功能提交；
2. 运行全量测试与必要的本地检查；
3. 确认工作区干净后创建整合提交；
4. 先推送 GitHub `main`，再将同一提交推送到 `tencent`；
5. 核对本地、GitHub、服务器裸仓库、服务器工作目录和 `eytle.cn` 的版本及关键文件内容。

部署前遵循根目录的 `CODEx_DEPLOY_GUIDE.md`，并保持 `scripts/deploy-excludes.txt` 与服务器排除规则一致。发布记录和备份不进入公开网站目录。
