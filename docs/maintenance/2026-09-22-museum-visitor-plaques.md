# 画廊访客铭牌 · 功能交接

本功能在 `codex/museum-visitor-plaques` 独立工作树中开发，基于 `main` 的 `7b6a7e0`。不包含上一项音乐音量提交 `29e7735`；发布会话合入两项时，保留该提交的音量调整，并使用本功能的新版 `museum.js` 缓存参数。

## 访客体验

- 每幅画右侧增加象牙色、铜边的信息铭牌，面对左右两面展墙时都处于画作右侧。中心离地 1.37 m，距画框至少 0.16 m，始终落在原有墙面与碰撞安全范围内。
- 参考 [Smithsonian 的展览无障碍设计指南](https://www.sifacilities.si.edu/sites/default/files/Files/Accessibility/accessible-exhibition-design1.pdf)：展签位置应一致，建议中心高度约 1370 mm，并通过颜色或凸起表面使其可辨认。
- 左键点击铭牌沿用 0.6 秒靠近动画，观看距离由画作的 1.7 m 调整为 0.64 m。随后释放鼠标并打开键盘可操作的铭牌阅读面板；关闭后返回进入前的位置与视角。输入文字时移动按键不起作用。
- 面板区分取名和评论；名称最多 40 个字符，评论最多 280 个字符。候选名称按票数排列，全部内容可分页读取。每个匿名访客对同一画作保留一票，可取消或改投；提交名称不会自动点赞。票数最高且至少获一票的名称成为展示名，同票先提出者优先。
- 展示名同步到原来画作下方的小铜牌；扩展铜牌宽度以便阅读。题名始终跟随稳定的画作文件名，而非无限长廊的区块序号。服务不可用时展馆仍可游览，留言面板明确显示不可用状态，不把浏览器本地数据伪装成共享留言。
- 保留中、英、韩三语。3D 铭牌材质按当前驻留作品共享，区块回收后释放不再使用的纹理。共享标题每 30 秒刷新一次，面板成功写入后立即更新本窗口对应题名牌。

## 文件与发布

- `js/museum.js`：交互状态、铭牌接入、题名刷新；`museum.html` 引入新样式并刷新入口脚本缓存。
- `js/museum-plaque-layout.js`、`js/museum-plaques.js`：铭牌位置、实体显示与题名纹理。
- `js/museum-guestbook.js`、`js/museum-guestbook-proof.js`、`css/museum-guestbook.css`：留言面板、同源 API 客户端和独立线程提交验证。
- `server/museum_guest_api.py`：共享数据服务。数据库和密钥必须位于网站及源码目录以外；服务仅监听回环接口，由 Nginx 代理。
- `scripts/deploy-excludes.txt`：排除服务源码及数据库、密钥文件，避免公开发布。

服务启动、Nginx/systemd 配置、限额、匿名投票的边界、内容隐藏与备份方法见 [服务维护说明](museum-guestbook-service.md)。静态文件发布不会自动安装或启动服务；发布会话需要一起部署 API，并检查取名、投票、评论与备份。

本地集成预览（数据库独立于工作树）：

```sh
python3 server/museum_guest_api.py serve --db /tmp/eytle-museum-guests-preview/guestbook.sqlite3 --dev-static --port 8001
```

入口为 `http://127.0.0.1:8001/museum.html`；自动漫游为 `museum.html?perf=walk`。普通 `python -m http.server` 只提供静态文件，不能存储共享评论。

- 修改的 JS 语法检查及 `git diff --check` 通过。源码未包含预览数据库、开发密钥或临时 `_shots` 检查页面。
- 浏览器实测：点击靠近、名称提交、点赞后正式题名、评论提交、重新打开的数据恢复、Esc/关闭按钮返回。画作正面检查确认右侧铭牌和下方铜牌的位置及题名内容。
- 主动停止并重启本地服务：面板如实提示断线、禁用提交；重新连接后名称、票数和评论恢复，尚未提交的输入草稿保留。
