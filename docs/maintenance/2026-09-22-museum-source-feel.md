# 展馆第一人称操作重制 · 2026-09-22

基于 `main` 的 `7b6a7e0`，独立分支 `codex/museum-source-feel`，工作树 `/tmp/eytle-museum-source-feel`。这是功能提交，未合并或推送；发布由“Eytle 网站发布会话”处理。

## 操作与实现

保留 Three.js r186 与现有展馆，重做浏览器第一人称控制器。借鉴 Source 系列的地面加速、摩擦和投影加速思路，自行实现轻量米制运动；不是 Source 2 移植，也不声称精确复刻 CS2 数值或 subtick。

- WASD 默认跑动（4.5 m/s），Shift 慢走（2.1 m/s），Ctrl 按住蹲下（1.25 m/s），Space 短按跳跃、长按落地自动连跳。斜向归一、反向刹车、空中有限控制，不能无限叠加速度。松开空格或暂停后不再自动起跳。
- 120 Hz 固定物理步进与相机插值。长时间停顿最多补算 100 ms，避免后台恢复后瞬移；没有持续走路镜头上下晃动。
- 站立眼高 1.65 m，蹲姿 1.08 m；垂直视野从 64° 调整为 74°，提高第一人称空间感。墙边安全距离与动态后墙保持现有边界。
- 原始鼠标输入优先，仅在不支持 raw input 时回退；鼠标即刻更新视角，正常快速甩动不再截断到每次 200 像素。右键放大时按视野缩小灵敏度。
- E 或左键查看画作、再次按下返回；保留右键放大和 Esc 暂停。聚焦、解锁、失焦、切后台清理输入，菜单不能被隐藏的键盘焦点误触进入。
- 三语操作提示；折叠设置仅提供鼠标灵敏度和 60 / 90 / 120 FPS 上限，保存于本地，默认 60 FPS。没有画质选项。

## 原画质约束

用户明确要求画质不变，所有降分辨率、低档渲染及反射降频方案已撤回。

保持原 DPR 上限 2、半浮点目标与最多 4× MSAA、半尺寸选择性泛光、1024 上限的逐呈现帧平面反射、AgX、曝光、材质、光照、雾、展品预览纹理与加载范围。`museum-architecture.js`、`museum-atmosphere.js`、灯具和泛光模块均未修改。

性能改动仅限调度：活动中按用户帧率上限呈现完整原画质；入口/暂停完成待加载任务后不重复绘制，窗口改变或纹理更新时补一帧；漫游切后台停止动画循环和队列上传。初始化尚未完成时的资源预载、着色器预热仍可能发生。WebGL 丢失时停止循环并释放待上传 Promise，切换标签页不会重新启动失效上下文。

## 验证

- `node --test --test-isolation=none tests/*.test.js`：98 项通过。包括 11 项运动行为、10 项真实控制区 VM 行为、10 项帧调度与真实主循环生命周期行为。
- 不同帧率的位移/跳跃一致、短按/同帧释放重按跳跃、斜向等速、蹲姿聚焦返回、暂停恢复、鼠标大幅转向、锁定失败回退、队列收尾和 WebGL 丢失均有实际行为覆盖。
- `node --check` 与 `git diff --check` 通过。
- 设置布局在中文、英文、韩文和六个窗口尺寸下，展开/折叠共 36 组检查通过；支持键盘操作，无横向溢出或控件重叠。
- 内置浏览器实际检查 1440×900 入口、设置、完整场景、自动漫游和区段/纹理回收；未报告新的浏览器错误。入口静止阶段两次观测的已呈现帧数均为 2，操作设置不会让展馆持续重画。
- 最终自动漫游超过 500 m。1440×900、DPR 1、60 FPS 上限的一个 600 帧窗口：帧间隔 p95 20.9 ms / p99 27.9 ms，取样帧 508 次绘制调用，78 张纹理，178 个几何对象；累计 164 次纹理上传、36 次区段回收。该窗口有 3 帧超过 40 ms，并非稳定锁满 60 FPS 的承诺。取样位置、视野与旧版不同，不用来声称活动帧加速百分比；主要节省来自暂停/后台和帧率上限。
- 内置浏览器仍拒绝 Pointer Lock；现在会显示可恢复的提示。手动鼠标锁定后的完整操作未在该浏览器完成，不能把 VM 测试表述为人工手感验收。

预览 `http://127.0.0.1:8767/museum.html`；自动漫游为 `?perf=walk`，`?perf=controls` 仅启用诊断数据，不绕过鼠标锁定。诊断数据在 canvas 的 `data-perf` / `data-presented`，不会显示在正常游客界面。
